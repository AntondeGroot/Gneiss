Reviews per session

How many cards already in rotation one session serves. An existing vault arrives with everything overdue at once, so a session takes a portion of it rather than all of it. Finish one and you can start another — this sizes a sitting, not a day.

This and the next number are one budget. Whichever runs out gives its room to the other, so a session stays the same size whether or not there is new material waiting.

New cards per session

How much unseen material one session introduces, so a large vault cannot arrive all at once. A card that needs real thinking is not the same work as one answered in a second — if sessions feel heavy, this is the number to lower.
